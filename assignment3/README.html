DLT Camera Calibration Demo

Overview

This interactive demo allows you to perform Direct Linear Transform (DLT) camera calibration using a 3D Rubik’s Cube as the calibration target. You’ll learn how to estimate the camera projection matrix P from 3D-2D point correspondences.

What’s Included

  • dlt_rubiks_demo.html - Interactive web-based calibration interface
  • dlt_server.py - Python backend for DLT computation
  • README.md - This file
  • Assignment_DLT_Calibration.md - Student assignment instructions

Quick Start

Step 1: Start the Python Server

Open a terminal/command prompt in this folder and run:

python dlt_server.py

You should see:

DLT Server running on http://localhost:8765
Press Ctrl+C to stop

Note: Keep this terminal window open while using the demo.

Step 2: Open the Demo

Open dlt_rubiks_demo.html in your web browser: - Option 1: Double-click the HTML file - Option 2: Right-click → Open with → Your browser - Option 3: Drag the file into your browser window

Step 3: Perform Calibration

  1. Select 3D Point Type (left panel):

    • Corners (8 points) - easiest, but coplanar
    • Edges (12 points) - better, some depth variation
    • 4×4×4 Vertices (125 points) - excellent coverage
    • 3×3×3 Cubelet Centers (27 points) - good balance
    • 3×3 Facelet Centers (54 points) - moderate

  2. Choose Units: “units” (1 cube = 3 units) or “mm” (1 cube = 57mm)

  3. Click 3D Points on the cube (left canvas):

    • Red circles show selected points
    • Shows world coordinates (X, Y, Z)

  4. Click Corresponding 2D Points on the image (middle canvas):

    • Click the SAME feature in the image
    • Yellow circles mark your selections
    • Shows pixel coordinates (u, v)

  5. Compute DLT:

    • Need minimum 6 point pairs
    • Click “Compute DLT” button
    • View results: P matrix, reprojection error, camera parameters

  6. Analyze Camera (right panel):

    • Click “Align to Cube” to visualize camera position
    • See decomposed K, R, t matrices
    • View camera center location

Understanding the Results

Projection Matrix P

The 3×4 matrix that maps 3D world points to 2D image points:

P = K[R | t]

Reprojection Error (RMSE)

  • Measures accuracy in pixels
  • Lower is better
  • < 1.0 pixel: Excellent
  • 1-3 pixels: Good

  • 5 pixels: Poor (check your point selections)

Camera Parameters

  • K: Intrinsic matrix (focal length, principal point)
  • R: Rotation matrix (camera orientation)
  • t: Translation vector
  • C: Camera center in world coordinates

Tips for Best Results

  1. Use Non-Coplanar Points: Select points with good 3D spread (depth variation)
  2. Avoid Corners Only: Corners are all on the surface; use cubelet centers or 4×4×4 grid
  3. Be Precise: Click accurately on both canvases
  4. Use More Points: 12-20 points give better results than minimum 6
  5. Check Reprojection: Red lines show errors; shorter = better
  6. Export/Import: Save your correspondences to reproduce results

Common Issues

“Failed to fetch” Error

  • Problem: Python server not running
  • Solution: Start dlt_server.py first

High Reprojection Error

  • Problem: Inaccurate point clicking or coplanar points
  • Solution:
    • Use cubelet centers or 4×4×4 grid
    • Click more carefully
    • Use more point pairs

Camera Faces Wrong Way

  • Problem: Normal for some point configurations
  • Solution: Code automatically orients camera toward scene center

Theory Background

DLT Algorithm

  1. Build matrix A from point correspondences (2 equations per point)
  2. Solve Ap = 0 using SVD (Singular Value Decomposition)
  3. Reshape solution into 3×4 matrix P
  4. Optionally normalize points for better numerical stability

Normalization

The code includes Hartley normalization: - 2D points: translate to centroid, scale so mean distance = √2 - 3D points: translate to centroid, scale so mean distance = √3 - Improves numerical conditioning

Decomposition

Given P, extract: - K (intrinsic): via RQ decomposition of M = P[:, :3] - R (rotation): from QR factorization - t (translation): from P[:, 3] - C (camera center): from null space of P or C = -R^T·t
