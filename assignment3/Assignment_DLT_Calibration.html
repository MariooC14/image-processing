Task 2.2: Implement Normalized DLT (8 marks)

Modify compute_dlt() to use normalization:

Currently (around line 77-82), the function builds matrix A directly:

A = build_A(world_pts, image_pts)

Your task: Modify the code to:

  1. Normalize 2D points:

    T, image_pts_norm = normalize_2d(image_pts)

  2. Normalize 3D points:

    U, world_pts_norm = normalize_3d(world_pts)

  3. Build A from normalized points:

    A = build_A(world_pts_norm, image_pts_norm)

  4. Compute P_tilde from SVD (same as before)

  5. Denormalize to get final P:

    P = np.linalg.inv(T) @ P_tilde @ U

Deliverable: - Modified dlt_server.py with your changes clearly marked with comments: python # === NORMALIZATION ADDED BY [YOUR NAME] === # Your code here # === END MODIFICATION === - Include the complete modified compute_dlt() function

  2. (2 marks) Explain WHY normalization helps DLT. What numerical problem does it address?
